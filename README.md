## Introduction

In this project of mine called Tic-Tac-toe, as the name suggests I made a simple and fun game that is loved by everyone to play during leisure times. With its simple and feature rich ui, the players have a lot more options to explore like choosing their icons, markers, as well as an ability to play with a simple and fun ai that will counter player's every move effectively but if the game gets too much stale, the A.I can lower its intelligence to make gaming more fun. The game features a majestic and minimalistic ui that offers * 3 rounds game * for the players to play even with A.I and offers a simple 3 x 3 grid to play on. So, let's not waste our time contemplating more about it and jump straight into action by playing it.

## Features

The game offers many rich features including some customizable options for setting up player names and rich gallery of icons to choose from, as well as there's some other features as well, let's look into them

- 3 round gameplay with final winner logic
- Play against an AI or human opponent (your choice).
- AI randomly but intelligently picks an empty cell and places it token.
- Choose between X or O markers
- Custom name and icon selections for both players 
- Elegant and beautiful ui with animated player cards and glowing tokens
- Scoreboard and turn indicators
- Visual feedback and game end alerts
